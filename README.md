Smart Greenhouse – Plant Health Prediction

About the Project

This project focuses on predicting plant health in a smart greenhouse using Machine Learning and Deep Learning.

Files

- "smart green house.ipynb": Jupyter Notebook containing the project code.
- "smart_greenhouse_dataset.csv": Dataset used for training and analysis.

Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow
- Keras
- YOLO

Project Goals

- Analyze greenhouse data.
- Predict plant health.
- Apply Machine Learning models.
- Explore Deep Learning techniques.
- Improve smart greenhouse monitoring.

Status
